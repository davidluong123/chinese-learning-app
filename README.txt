HOME SCREEN SETUP

1. Upload all files in this folder to any HTTPS static host (GitHub Pages is free).
2. Open the hosted URL in Safari on iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Keep the name “中文 30 phút” or rename it, then tap Add.

Important: iPhone Home Screen web apps require a web URL. Opening index.html directly from the Files app is not enough for the full PWA behavior.
